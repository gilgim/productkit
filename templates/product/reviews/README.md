# reviews/

현재 정의 내용에 대한 AI Review 기록. `REV-xxx`.

검토 대상: UX 모순, 이상한 사용자 흐름, 빠진 상태, 불필요한 복잡도, 정책 간 충돌,
Acceptance Criteria의 모호함.

- 각 Review는 평가 대상 내용의 hash와 발견한 Finding 참조를 남긴다.
- 내용이 바뀌어 hash가 달라지면 그 Review는 stale이고 Gate가 막는다.
- 기계 검증은 Review의 존재·형식·최신성·미해결 Finding만 확인한다. 의미적 타당성을
  스스로 검증했다고 주장하지 않는다.

필드 계약: ProductKit의 `docs/artifact-contracts.md` — Review.
