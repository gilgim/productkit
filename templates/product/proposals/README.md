# proposals/

Finding에 대한 대안과 trade-off. `PROP-xxx`.

각 option은 description, benefits, costs, risks, assumptions를 모두 갖는다. 장점만
나열한 대안은 대안이 아니다.

- 억지로 세 개를 만들지 않는다. 의미 있는 대안 2~3개가 기본이다.
- 제외·유예가 유효한 선택이면 option으로 포함한다.
- `recommendation`은 추천일 뿐이다. 추천을 제시한 상태는 `pending`이며 Decision이
  아니다.

필드 계약: ProductKit의 `docs/artifact-contracts.md` — Proposal.
